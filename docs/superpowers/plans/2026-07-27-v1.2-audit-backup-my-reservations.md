# v1.2 Audit, Backup, and My Reservations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add atomic operation auditing, verified scheduled SQLite backups, and a unified personal reservation view while production remains on v1.1.0.

**Architecture:** Extend the existing SQLite and dependency-free Node service rather than adding a framework. Audit entries are written inside the same database transaction as each mutation and exposed through role-aware service and HTTP boundaries. Personal reservations are merged on the server from equipment and room reservations so lifecycle status has one authoritative implementation; the frontend consumes that endpoint as a focused workspace view.

**Tech Stack:** Node.js 22+, `node:sqlite`, `node:http`, vanilla HTML/CSS/JavaScript, Node test runner, systemd.
