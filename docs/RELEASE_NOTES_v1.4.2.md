# 实验室资源平台 v1.4.2 发布说明

日期：2026-09-18。

## 修复

- 修复自动升级代理在 `/tmp` 与 `/opt` 位于不同文件系统时出现 `EXDEV`、导致发布目录无法切换的问题。
- 发布目录现在采用跨文件系统安全复制，并在复制完成后清理临时目录。
- 保留旧 release 和数据库快照，失败时仍可自动恢复代码版本。

## v1.4.1 功能

- 帮助教程更完整，覆盖开发者、管理员、普通用户、升级和回滚。
- 系统升级页提供自动升级和可复制的手动升级方法。

## 升级

- 当前公网 v1.4.0 仍可从“系统升级”页面检查到 v1.4.2。
- v1.4.0/v1.4.1 已安装升级代理的环境无需重新部署，直接点击“检查更新”后升级。
- v1.3.0/v1.3.1 环境可使用 `scripts/upgrade-lan-from-v1.3.sh v1.4.2` 快速升级。
