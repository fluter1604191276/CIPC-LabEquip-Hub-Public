# CIPC LabEquip Hub 项目计划

## v1.1.0 本地迭代目标

当前分支只在本地验证，不连接或修改生产环境。本轮以降低高频操作阻力、补齐台账维护能力和改善可访问性为目标：

- 设备详情支持编辑名称、资产编号、性能指标、所在实验室和保管人，状态继续独立管理。
- 已登录用户可从侧边栏修改自己的密码；改密后其他登录会话失效。
- 搜索输入使用短延迟防抖，避免设备、成员和资源列表在连续输入时重复渲染。
- 预约时间错误在表单内即时提示；失败 Toast 使用明确的错误样式和读屏器提示。
- 弹窗和抽屉具备初始焦点、Tab 焦点约束、Escape 关闭和焦点恢复。
- 提升关键控件对比度，补充跳至主内容入口以及筛选按钮的选中状态语义。
- admin 与 developer 可在核对关联记录数量并二次确认后强制删除设备及其预约、维修保养和采购记录；服务端在删除事务内校验确认快照，防止并发新增记录被误删。

完成标准：API 与 Web 回归测试全部通过，并在桌面端和 390px 移动视口完成登录后核心流程验证。生产部署另行安排。

## MVP 范围

- `member`、`admin`、`developer` 三种角色；admin 增加成员管理与设备强制删除，developer 可切换三种视图并保留真实开发者权限。
- 设备台账、直接生效的预约与数据库重叠校验。
- member 范围内的维修保养与采购视图和记录。
- 初始密码改密、随机临时密码重置和会话失效。
- 单机 SQLite、可演练的备份恢复与 VPS 进程守护。

## 不在当前范围

- 预约审批、批准、驳回和保管人责任审批。
- 自助注册、公开预约、外部身份提供商。
- 对象存储、邮件通知、物联网接入、使用计费和复杂报表。

## 交付顺序

1. 完成角色与界面权限的端到端验证。
2. 完成设备、预约、维修保养和采购的实际数据流。
3. 以 systemd、Nginx `/api` 代理和持久 SQLite 文件部署单机服务。
4. 演练 `VACUUM INTO` 备份、恢复、健康检查和 release 回滚。
5. 在真实数据录入前补齐审计、通知、迁移和更细粒度权限的需求评估。
