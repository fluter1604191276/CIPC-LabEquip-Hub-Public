# 互动教程：真实界面复用计划

2026-09-19，继续本地开发；不发布、不切换生产。

## 目标与保留行为

当前独立绘制的模拟侧栏、列表、表单与真实系统存在差异。本轮删除重复业务 UI，直接使用本版本 `index.html` + `styles.css` + `app.js`，仅在其上添加教学高亮与讲解层。

保留九个教程、分角色目录、自动演示/动手练习、返回与重启、错误校验、完整退出清理。现有 125 项测试先作为行为基线，新增真实 UI 与虚拟接口回归。

## 实施边界

1. 将 app.js 包装为可挂载到指定文档的工厂，正式启动行为不变；演示模式必须提供内存接口，拒绝所有网络回退。
2. 使用静态源模板与原 CSS 填充脚本禁用 iframe。保留真实元素、原按钮/菜单名称、输入约束和弹窗。
3. 教程只引用真实选择器，不重新实现设备表格、成员列表、日历或业务表单。
4. 新增纯内存数据适配器：真实 UI 的请求只作用于虚构数据；隔离存储、剪贴板、导出和升级确认；不访问生产账号或数据库。
5. 交互对齐：搜索输入即筛选，••• 打开详情，取消直接完成，验收选择即保存，新增/编辑共享原表单。
6. 讲解区域与业务界面分开；移动端沿用正式 CSS 的菜单断点。

## 验证

- 原业务测试保持通过；适配器未知路由失败关闭，返回数据拷贝。
- 浏览器逐课使用真实控件完成，记录业务请求零外发。
- 在既有生产 CSP 下运行；桌面/手机截图比对关键控件 DOM、样式来源与尺寸。
- 清理自动演示、应用防抖/问候/轮询定时器；关闭、角色切换、返回练习均不残留实例。

视觉上的教学标记和虚构数据会与生产不同；业务布局与控件使用同一份源码，不再维护另一套仿制界面。
