# 实验室资源平台 v1.3.1 发布说明

日期：2026-09-18。发布状态与生产落地记录见 `VERSION_MATRIX.md`。

## 功能与修复

- 登录页、导航、标题、帮助和下载文件名采用通用实验室平台名称。
- 管理员和开发者可新增、编辑实验室/空间的名称、编号、别名、排序和启用状态，服务端独立鉴权并记录审计。
- 实验室改名同步设备当前归属，成员通过实验室 ID 保持关联；历史预约快照保持原样。
- 停用阻止新分配，已有归属可以保留，重新启用后恢复选择；停用不自动停用设备或会议室预约。
- 修复编辑默认实验室后重启重复生成旧空间的问题：已有实验室时不重复播种默认项。
- 保存实验室后重新加载设备与成员关联信息；保留普通用户编辑停用/旧实验室下设备的能力。
- 更新静态资源版本参数，减少升级后使用旧脚本/样式的问题。

## 升级与回滚

- 保留现有 Cookie、数据库路径与 systemd 单元名称，不要求重建数据库或重置账号。
- 先创建经过完整性检查的 SQLite 快照，再切换代码 release、重建前端容器、重启 API。
- 本次不更改站点域名、TLS、生产账号或学校主机。
- 出现运行异常时切回上一 release；代码回滚不自动恢复数据库，以免丢弃发布后新增业务数据。
- 若曾改名实验室，再回退旧代码，旧播种逻辑可能补回默认项；业务开放后的回滚须核对实验室清单。

## 验证

- 本地静态语法检查通过，完整测试 100/100 通过。
- 覆盖权限、改名联动、停用分配、审计失败事务回滚和重启持久化。
- 生产验收在 release 切换后检查 API、静态资源哈希、数据库完整性和容器状态。
