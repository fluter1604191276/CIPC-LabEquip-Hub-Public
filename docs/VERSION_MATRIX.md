已部署 v1.3.0、v1.4.10、v1.4.11、v1.4.12 或 v1.4.13 的环境，可按 [发布、迁移与部署流程](RELEASE_AND_MIGRATION.md) 中的 v1.4.14 快速升级步骤处理。数据库、备份、实际人员账号、服务器网段和本机凭据不从 GitHub 获取，必须按部署文档单独初始化或迁移。
