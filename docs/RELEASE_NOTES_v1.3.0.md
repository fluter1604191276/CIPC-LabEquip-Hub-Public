# CIPC LabEquip Hub v1.3.0 发布说明

状态：已于 2026-09-16 完成代码验收并发布 GitHub；原公网生产环境已于 2026-09-17 升级到 `v1.3.0`。学校机房可按 Ubuntu 局域网方案部署同一标签。

## 管理与规模化

- 管理员和开发者可新增、编辑、启用及停用会议室。
- 会议室存在尚未结束的预约时禁止停用，并返回关联预约数量。
- 数据库触发器保证会议室停用与新预约在多进程写入时仍保持一致。
- 存在未来预约时，会议室容量不能下调到预约人数以下。
- 预约、会议室预约、维修保养、采购与审计接口支持服务端分页、状态和日期范围筛选。
- 审计中心支持关键词、对象类型、时间范围筛选、分页和 CSV 导出。
- 登录失败写入不含密码或令牌的系统审计事件。
- 登录失败按账号和可信代理来源双重限流，限流记录使用固定容量存储。
- 浏览器 API 请求设置 15 秒超时，并统一显示中文网络错误。
- 新增局域网部署方案：Nginx 仅允许私有网段，API 继续只监听回环，不配置公网域名。
- 增加 `COOKIE_SECURE` 显式开关，LAN HTTP 部署关闭，HTTPS 公网部署明确开启。
- `COOKIE_SECURE` 留空时跟随 `NODE_ENV` 的生产安全默认，避免复制配置模板后意外关闭 Secure Cookie。
- 生产 systemd 单元默认不播种演示账号，空数据库通过一次性管理员初始化脚本创建首个管理员。
- 会议室预约从取消状态恢复时，数据库会重新校验房间容量。
- 设备清单 CSV 对电子表格公式前缀进行转义。

## 运维闭环

- `/api/health` 提供轻量存活检查；SQLite 完整性、备份时效和磁盘容量由运维检查命令独立验证。
- `pnpm restore:drill` 在隔离副本中执行恢复、完整性检查和关键表检查。
- `pnpm operations:check` 检查 API、数据库、备份时效和磁盘剩余空间。
- 备份时效按不可变文件名时间戳判断，并拒绝过期或未来时间戳快照。
- 备份服务允许 SQLite WAL 读操作创建或映射相邻的 `-shm` 文件。
- 发布、回滚、恢复演练、定时运维检查安装和站点告警接入边界已写入 VPS 部署说明。
