# 实验室资源平台 v1.4.10 发布说明

发布日期：2026-09-19

## 本版重点

v1.4.10 优化系统升级页面的“检查更新”入口，不修改数据库结构和升级代理协议。

### 界面优化

- 将原有普通灰色按钮改成更醒目的橙色主操作按钮。
- 增加独立同步图标和“获取最新稳定版”辅助说明，使操作目的更直观。
- 检查期间显示“正在检查…”，图标进入旋转状态，并通过 `aria-busy` 告知辅助技术当前状态。
- 为减少动态效果的用户关闭旋转动画；移动端按钮通栏显示，便于触控。
- 增加回归测试，覆盖按钮结构、检查状态反馈和 v1.4.10 静态资源缓存版本。

## 升级验证安排

- v1.4.10 只推送公开仓库并创建 Release。
- 公网生产继续保持 v1.4.9，由开发者在页面点击“检查更新”后使用“备份并升级”验证自动升级链路。
- 自动升级应完成 SQLite 快照、发布包测试、代码切换、API/Web 重启和健康检查。

## 兼容性

- 兼容 v1.3.0 及之后的生产数据库。
- 不修改账号、实验室、设备、预约或审计数据。
