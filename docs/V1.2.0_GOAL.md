# CIPC LabEquip Hub v1.2.0 Goal

## Objective

在不改动线上 `v1.1.0` 的前提下，完成一轮面向日常运行可靠性与个人工作效率的本地迭代，使关键业务变更可追溯、数据库可自动生成一致性备份，并让每位成员集中管理自己的设备与会议室预约。

## Scope

1. **操作审计**
   - 覆盖设备、成员、预约、维修保养、采购与密码变更等关键写操作。
   - 审计记录与业务写入处于同一事务；失败的业务操作不留下成功审计。
   - 管理员和开发者可查看全部记录，普通成员只可查看本人操作。
   - 审计摘要不保存密码、密码哈希、会话令牌或临时密码。
2. **我的预约**
   - 合并展示当前用户的设备预约与会议室预约。
   - 支持按已生效、使用中、已完成、已取消筛选。
   - 可沿用既有规则取消未来预约，并进入对应资源的预约日历。
3. **自动备份**
   - 使用既有 `VACUUM INTO` 一致性快照脚本。
   - 备份完成后执行 SQLite 完整性校验，失败时保留明确退出状态。
   - 提供每日执行的 systemd oneshot 与 timer 模板、保留数量配置和恢复说明。

## Non-goals

- 本轮不部署生产，不调整 VPS 网络、VPN、Caddy 或 Cloudflare 配置。
- 不引入 PostgreSQL、大型后端框架、审批流或第四种角色。
- 不实现附件、批量导入导出或高级报表。

## Acceptance Criteria

- 关键写操作均产生内容可读且不含敏感字段的审计记录。
- 审计权限由真实登录角色在服务端强制执行，开发者的前端视图切换不影响授权。
- “我的预约”只包含当前账号创建的设备和会议室预约，状态与全局日历一致。
- 自动备份可在临时数据库上生成通过 `PRAGMA integrity_check` 的快照，并正确执行保留策略。
- `pnpm check` 全量通过，桌面与移动视口的新增界面无溢出或遮挡。
- Git 工作仅存在于 `codex/v1.2-audit-operations`，线上继续运行 `v1.1.0`。
