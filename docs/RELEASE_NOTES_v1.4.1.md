# 实验室资源平台 v1.4.1 发布说明

日期：2026-09-18。

## 帮助教程

- 扩充开发者、管理员和普通用户的工作指南，增加每日操作顺序、维护边界、升级前后检查和高风险操作提示。
- 新增开发者专属“系统升级”教程，说明自动升级、手动升级、维护窗口和代码/数据库回滚原则。
- 常见问题增加自动升级不可用时的处理方法。

## 升级中心

- 系统升级页新增可复制的手动升级命令。
- 手动命令默认使用当前检查到的稳定标签；未检查时提供 v1.4.1 示例。
- API 当前版本从实际 release 的 package.json 读取，避免旧 systemd 环境变量导致版本显示错误。
- 保持自动升级流程：备份、测试、切换、健康检查和失败回滚。

## 兼容性

- v1.4.0 已安装升级代理的学校部署，可在公网发布 v1.4.1 后直接从“系统升级”点击升级。
- v1.3.0/v1.3.1 旧部署仍可使用仓库中的快速升级脚本升级到 v1.4.1。
- 本版本不修改生产数据库结构，不需要重新初始化账号。
