# CIPC LabEquip Hub v1.2.0 发布说明

状态：已于 2026-07-28 发布生产。

## 新增

- “我的预约”合并当前账号的设备和会议室预约，并支持生命周期筛选、取消和资源日历跳转。
- 预约日历新增固定 42 格月视图、当日完整详情和资源日历联动；侧边栏按日常工作流重新分组。
- 中文界面改为系统中文字体优先，并重新设计总览空状态的字号与信息层级。
- 关键设备、成员、预约、维修保养、采购和密码操作的追加式审计记录。
- `GET /api/my-reservations?status=STATUS` 与 `GET /api/audit-logs`。
- 经 SQLite 完整性校验的备份输出，以及每日 systemd oneshot/timer 部署模板。

## 权限与一致性

- 个人预约始终按真实会话用户过滤。
- member 的审计 API 只返回本人操作；admin 和 developer 返回全部记录。
- developer 的模拟视图切换不改变服务端身份或审计范围。
- 业务变更与审计写入处于同一事务；敏感凭据字段不进入审计摘要。
- 取消预约使用带状态与开始时间条件的原子更新，消除预约刚开始时仍被取消的竞态窗口。

## 运维

- `scripts/backup-db.mjs` 继续使用 `VACUUM INTO` 获取包含 WAL 内容的一致性快照。
- 新快照必须通过 `PRAGMA integrity_check`；无效输出会被删除并返回失败。
- `deploy/vps/cipc-labequip-backup.service` 与 `.timer` 已在生产安装并启用。

## 发布约束

- 本候选版本不包含 PostgreSQL 迁移、审批流、附件、批量导入导出或高级报表。
- 发布前已完成本地全量测试、桌面与移动浏览器验收、数据库一致性快照和公网健康检查。
