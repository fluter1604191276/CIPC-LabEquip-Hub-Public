# 实验室资源平台 v1.4.8 发布说明

发布日期：2026-09-19

## 本版重点

v1.4.8 是 v1.4.7 的前端修正版，业务数据模型和升级代理保持兼容。

### 升级中心修复

- 修复系统升级页面在尚未点击“检查更新”时，把手动升级命令错误显示为旧版 `v1.4.1` 的问题。
- 只有检查到确实可升级的稳定版本后，页面才生成带目标版本号的手动升级命令。
- 尚未检查版本时显示操作提示；当前已经是最新版本时不再显示可执行的误导性命令，并禁用复制按钮。
- 增加前端回归测试，避免后续重新加入过期硬编码版本。

## 兼容性与升级

- 兼容 v1.3.0 及之后的生产数据库。
- 不修改数据库结构，不要求重新创建账号、实验室、设备或预约数据。
- 已安装升级代理的环境可在“系统升级”页面检查并升级到 v1.4.8；升级前仍会创建数据库快照。
- 自动升级服务不可用时，先在页面点击“检查更新”，再复制页面生成的目标版本命令，不要手工填写旧版本号。
