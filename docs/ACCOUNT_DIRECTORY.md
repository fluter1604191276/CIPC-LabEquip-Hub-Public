# 账号目录

系统没有自主注册。账号由管理员维护，角色只有三种：

| 角色 | 范围 |
| --- | --- |
| `member` | 设备、预约、维修保养与采购视图和流程 |
| `admin` | 成员的全部范围，另可管理成员账号 |
| `developer` | 用于维护和验收，可切换 member、admin、developer 三种界面视图 |

本地开发模式会生成虚构测试账号，初始密码为 `123456`，仅用于本机演示和自动化测试。生产 systemd 单元设置 `SEED_DEMO_USERS=false`，不会创建这些账号。

## 部署账号

公开仓库不记录真实部署人员姓名、用户名或密码。全新的生产数据库必须先运行一次 `scripts/bootstrap-admin.mjs` 创建首个管理员，然后由管理员：

1. 使用初始化时设置的管理员账号登录；
2. 在“成员与权限”页面按实际实验室人员创建账号；
3. 将初始密码通过受控渠道单独交给成员，并要求首次登录改密；
4. 不要把真实账号名单、临时密码或重置结果提交到 Git 仓库。

本地测试账号的具体用户名不应直接作为生产账号目录。

## 密码重置

管理员在成员页面重置密码时，系统生成随机临时密码并仅在该操作结果中显示一次。重置会注销目标账号全部会话，并要求该账号下次登录后立即改密。应通过受控渠道单独传递临时密码，且不写入本文件、聊天记录或工单正文。
