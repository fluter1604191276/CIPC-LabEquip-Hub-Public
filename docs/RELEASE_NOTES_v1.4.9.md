# 实验室资源平台 v1.4.9 发布说明

发布日期：2026-09-19

## 本版重点

v1.4.9 是 v1.4.8 的发布缓存修正版，业务数据模型和升级代理保持兼容。

### 前端发布修复

- 将 `styles.css` 和 `app.js` 的查询版本同步到 v1.4.9，避免浏览器继续使用 v1.4.7 的缓存资源。
- 确保 v1.4.8 修复的手动升级版本显示逻辑在公网升级后立即生效。

v1.4.8 的功能修复仍然包含在本版中：未检查更新时不生成旧版本命令，当前已是最新版本时禁用手动升级复制按钮。

## 升级方式

已安装升级代理的环境可从“系统升级”页面检查并升级到 v1.4.9。手动维护时请先获取 v1.4.9 标签，再执行仓库中的升级脚本。
