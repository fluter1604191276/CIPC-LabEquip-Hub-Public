# 实验室资源平台 v1.4.11 发布说明

发布日期：2026-09-19

## 本版重点

v1.4.11 新增与正式页面同源的交互式使用指南，并修复 Safari/WebKit 下教程点击无响应的问题。业务数据库结构保持兼容。

### 交互式使用指南

- “使用指南 → 边做边学”直接复用正式版本的页面结构、样式、导航、表单、抽屉和业务交互。
- 普通用户提供 6 个教程；管理员提供成员与实验室管理教程；开发者额外提供系统升级演练。
- 支持动手练习、自动演示、暂停、上一步、重新开始、错误提示、移动端导航和完成回顾。
- 教程使用纯内存虚拟数据，未知请求拒绝处理，不会创建真实预约、账号、记录、备份或升级任务。
- 生产界面的实际字段、按钮和交互被保留，降低培训后正式操作的迁移成本。

### Safari/WebKit 兼容性

- 修复 Safari 下点击正式界面演示副本无响应的问题。
- 两层教程 iframe 使用 WebKit 兼容的 sandbox 配置；子文档脚本仍通过 CSP `script-src 'none'` 和脚本剥离禁用。
- 继续保留 `connect-src 'none'`、`form-action 'none'`、内存请求适配器、剪贴板/下载隔离和退出清理。

## 兼容性与部署

- 兼容 v1.3.0 及之后的生产数据库。
- 不要求重新创建账号、实验室、设备、预约或审计数据。
- 已安装升级代理的环境可在系统升级页检查 v1.4.11；本次发布只上传公开仓库，公网生产暂不切换。
- 学校部署可先按迁移文档升级测试，确认界面与 Safari/Chrome 浏览器兼容后再安排生产窗口。

## 验证

```bash
pnpm check
```

本版本地验证包含 Chromium 与 WebKit 的九项教程实际点击、输入、提交、自动演示、暂停、移动端流程和生产 CSP 兼容检查；业务 API 写入请求为零。
