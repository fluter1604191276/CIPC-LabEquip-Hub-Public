# 实验室资源平台 v1.4.12 候选发布说明

开发记录日期：2026-09-19；状态：本地候选，尚未发布。

## 本版重点

v1.4.12 补充设备台账中的“新增设备”交互式教程。正式业务功能本身不变。

### 新增设备教程

- 普通用户、系统管理员和开发者均可看到“新增设备”教程，与现有设备台账权限一致。
- 教程复用正式的“新增设备”按钮和表单，覆盖设备名称、资产编号、性能指标、所在实验室、设备保管人和初始状态。
- 增加必填字段、长度、重复编号、停用实验室和状态选择等虚拟校验。
- 保存后使用正式台账列表核对新设备，所有数据仅保存在内存演示适配器中。

v1.4.11 的同源交互式指南、管理员/开发者教程和 Safari/WebKit 修复继续保留。

## 兼容性与发布安排

- 兼容 v1.3.0 及之后的生产数据库。
- 本次为本地候选版本，暂不切换公网生产；正式发布前需再次执行完整测试和浏览器回归。

- `pnpm check`：144/144 通过。
- Chromium 全部十项教程通过；WebKit 新增设备手动练习、自动演示及手机流程通过。
