# CIPC LabEquip Hub v1.1.0 发布说明

状态：已于 2026-07-27 完成本地、服务器测试并部署生产。

## 新增

- 从设备详情编辑名称、资产编号、性能指标、所在实验室和保管人。
- 已登录用户从侧边栏自助修改密码。
- 设备、台账、成员和预约资源搜索防抖。
- 预约时间范围的表单内即时校验。
- 管理员和开发者可在明确查看关联记录数量并二次确认后，强制删除设备及其全部预约、维修保养和采购记录。

## 体验改进

- 弹窗和抽屉支持焦点进入、Tab 约束、Escape 关闭与焦点恢复。
- 关键按钮、状态文字和输入提示提高对比度。
- 筛选与模拟角色按钮补充选中状态语义。
- 错误 Toast 使用独立颜色、图标和 `alert` 播报。

## 接口与验证

- `PATCH /api/equipment/:id` 支持部分更新设备业务字段，并保留状态更新兼容性。
- 设备编号继续执行不区分大小写的唯一约束。
- 所在实验室必须来自当前启用的实验室列表。
- API 覆盖 member、admin、developer 三种角色的设备编辑能力。
- `DELETE /api/equipment/:id?force=true` 仅允许真实身份为 admin 或 developer 的账号调用；请求携带已确认的 `expectedHistory`，服务端在同一事务中比对后删除设备及关联历史，数量变化时返回 `409` 并要求重新确认。

## 发布与回滚

- 生产发布目录为 `/opt/cipc-labequip/releases/20260727T135141Z-v1.1.0-wt`。
- 发布前已创建 SQLite 一致性备份；上一稳定 release 保留为代码回滚点。
- 生产数据维护必须先创建一致性备份并单独执行。
- 操作审计、自动备份调度与更细粒度资源权限继续保留在后续排单。
