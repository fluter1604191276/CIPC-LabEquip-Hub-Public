# 实验室资源平台 v1.4.0 发布说明

日期：2026-09-18。

## 开发者升级中心

- 开发者可在网页检查公开仓库的最新稳定版本。
- 升级请求只接受固定仓库和语义化稳定版本。
- systemd path/service 负责执行备份、下载、测试、代码切换、健康检查和失败回滚。
- 升级状态写入持久化 JSON，页面刷新后仍可查看。
- 数据库不会自动降级或回滚；数据库恢复继续使用现有备份流程。

## 安全边界

- 普通管理员和普通用户看不到升级页面。
- API 只允许真实开发者角色检查或提交升级，前端模拟角色不改变服务端权限。
- 网页不直接执行 shell；高权限操作由独立 systemd 升级代理完成。
- 升级代理只从固定公开仓库下载目标版本，不接受网页传入命令、路径或脚本。

## 部署

首次启用请安装对应的 `cipc-labequip-upgrade.service` 与 `.path`，详见 `deploy/lan/README.md` 和 `docs/RELEASE_AND_MIGRATION.md`。
