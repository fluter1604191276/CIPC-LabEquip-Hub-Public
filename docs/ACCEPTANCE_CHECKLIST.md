# MVP 验收清单

## 角色与流程

- [x] 仅存在 `member`、`admin`、`developer` 三种角色
- [x] member 可访问设备、预约、维修保养和采购视图
- [x] admin 在 member 能力之上增加成员管理和设备强制删除
- [x] developer 可切换 member、admin、developer 三种视图，切换不改变真实服务端身份
- [x] 预约创建后直接生效；不存在待审批、批准或驳回流程
- [x] member、admin、developer 均可查看会议室并创建直接生效的会议室预约
- [x] 会议室预约仅允许提交者取消；developer 可取消任意尚未开始的会议室预约
- [x] 设备与会议室预约按时间自动显示未开始、使用中和已完成
- [x] 已过开始时间不能新建预约，已开始或已完成的预约不能取消
- [x] 初始密码由管理员单独发放，首次登录必须改密
- [x] 管理员重置密码会生成随机临时密码、使旧会话失效并要求再次改密
- [x] 已登录用户可自助修改密码，当前会话保留且其他会话失效

## 数据与稳定性

- [x] 设备、预约、维修保养和采购写入共享 SQLite 数据库
- [x] 设备台账支持关键词、实验室、状态组合筛选以及三种排序方式
- [x] 设备清单可按当前筛选结果导出为 UTF-8 CSV
- [x] 台账统计仅使用现有设备数据，不展示未实现的设备实例或资料完整度概念
- [x] 所有业务角色均可在设备详情中修改四种设备状态；预约占用只从预约记录计算
- [x] 未完成维修保养记录会驱动设备进入维修中，全部完成后再恢复可用
- [x] 采购验收状态可后续更新，采购总额仅统计已验收记录
- [x] 无业务历史的设备可由所有登录用户移除；有历史的设备仅允许 admin 或 developer 二次确认后连带删除全部关联记录
- [x] 所有业务角色均可编辑设备名称、资产编号、性能指标、所在实验室和保管人
- [x] 同一设备的有效预约时段不能重叠
- [x] 预约日历提供周概览、固定 42 格月视图和可搜索的单项资源周日历
- [x] 月视图可展示每天预约摘要、超额数量和完整当日详情，并可跳转至对应资源日历
- [x] 侧边栏按工作台、资源与业务、管理分组，普通用户隐藏无权访问的管理入口
- [x] 同一会议室的有效预约时段不能重叠，且预约人数不超过会议室容量
- [x] 管理员和开发者可新增、编辑、启用及停用会议室
- [x] 存在未来预约时禁止停用会议室并返回关联数量
- [x] 审计记录支持服务端分页、关键词、对象类型和日期范围筛选
- [x] 审计筛选结果支持 CSV 导出
- [x] 综合健康检查覆盖 API、SQLite、备份时效和磁盘空间
- [x] SQLite 备份可在隔离副本中完成恢复演练
- [x] WAL 数据库在 API 停止且共享内存文件缺失时仍具备备份所需目录权限
- [x] 登录失败同时受账号和可信代理来源限制，限流记录数量有固定上限
- [x] 浏览器 API 请求具有 15 秒超时和统一中文传输错误提示
- [x] 局域网部署配置不依赖公网域名，入口按私有网段白名单限制
- [x] HTTP 局域网部署显式关闭 Secure Cookie，HTTPS 部署显式开启
- [x] `meeting_rooms` 与 `room_reservations` 持久化到共享 SQLite 数据库
- [x] `GET /api/meeting-rooms`、`GET/POST /api/room-reservations`、`PATCH /api/room-reservations/:id/cancel` 可用
- [x] API `/api/health` 在本机和本地 `/api` 反向代理路径均可访问
- [x] 使用 `scripts/backup-db.mjs` 创建 SQLite 一致性快照
- [x] 已按部署文档完成一次隔离备份和恢复演练

## v1.1.0 本地体验

- [x] 设备、成员和预约资源搜索采用防抖刷新
- [x] 预约时间错误在表单内显示并通过 `role="alert"` 提示
- [x] 成功与失败 Toast 使用不同视觉样式和读屏器播报优先级
- [x] 弹窗与抽屉支持初始焦点、Tab 约束、Escape 关闭和焦点恢复
- [x] 关键操作颜色满足对比度要求，筛选按钮暴露 `aria-pressed` 状态
- [x] 在桌面端和 390px 移动视口完成本地浏览器验收

## v1.2.0 本地候选

- [x] “我的预约”仅合并当前账号创建的设备和会议室预约
- [x] “我的预约”支持未开始、使用中、已完成和已取消筛选
- [x] 个人预约可沿用既有权限取消，并进入对应资源的单项日历
- [x] 关键设备、成员、预约、维修保养、采购和密码操作写入审计记录
- [x] 审计记录与业务写入使用同一事务，失败操作不会留下成功审计
- [x] 审计摘要不包含密码、哈希、盐值、令牌或临时密码
- [x] member 仅可通过 API 查看本人操作，admin 与 developer 可查看全部审计
- [x] 数据库快照在生成后执行 `PRAGMA integrity_check`
- [x] 自动备份 oneshot 与每日 timer 模板已纳入版本库，但尚未安装到生产
- [x] 在桌面端和 390px 移动视口完成 v1.2.0 本地浏览器验收
