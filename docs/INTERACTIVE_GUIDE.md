# 交互式使用指南（开发记录）

日期：2026-09-19。分支：`codex/interactive-guide`。

本轮仅开发与验证；没有创建发布标签、推送或切换生产。现有版本号保留，下次正式发布时再统一更新版本与资源缓存号。

## 交付范围

- 使用指南默认展示“边做边学”，文字指南保留。
- 9 个课程：界面导览、设备搜索与预约、取消本人预约、会议室预约、维修保养、采购验收、创建成员、新增与编辑实验室、系统升级演练。
- 按模拟角色/登录角色展示 6 / 8 / 9 个教程，不授予任何实际权限。
- 动手练习：高亮目标、输入示例、操作校验、错误提示、进度、返回上步、重新练习与完成小结。
- 自动演示：自动填写与操作，暂停/继续、返回练习；隐藏页面暂停演示。
- 指南关闭、登录失效、角色切换、转到文字指南时销毁教程文档、监听与计时器。
- 失败加载可重试，失败期间仍可进入文字说明。

## 文件与边界

- `apps/web/tutorial.html`：虚拟页面外壳和独立 CSS。
- `apps/web/tutorial.js`：静态课程、纯状态模型、绑定给指定 document 的教学控制器。
- `apps/web/app.js`：指南入口、静态 HTML 加载、角色选择、挂载与销毁。
- `apps/web/test/tutorial.test.mjs`：纯模型、验证逻辑及集成边界回归。

嵌入方式是 `iframe.srcdoc` + `sandbox="allow-same-origin"`，**不启用子文档脚本、原生表单提交或弹窗**。主页面的可信静态脚本只向独立文档绑定教学事件；子文档 CSP 额外设置 `script-src 'none'; connect-src 'none'; form-action 'none'`。控制器不调用业务 API、不导入业务状态，也不读写 cookie/localStorage。

这不是把真实业务页面放进 iframe；数据和状态均在教学模型内。可信主页面控制器本身仍属于主应用代码，不能将它描述为不具备访问主页面能力的第三方脚本沙箱。

该方案保留现有公网 `script-src 'self'` 与 `X-Frame-Options: DENY`，不要求修改代理配置。脚本从主页面加载，避免不透明来源 iframe 在校内私网加载脚本时产生额外浏览器网络权限请求。独立打开 `tutorial.html` 时默认普通用户教程；页面由同一个静态脚本自行初始化。

## 回归与验收

```bash
pnpm check
WEB_PORT=3100 node scripts/dev-web.mjs
```

浏览器测试使用本机 3100 端口及模拟登录/API 响应，不使用生产账号或生产数据。测试额外给主页面注入仓库 VPS CSP 与 X-Frame-Options 响应头，覆盖实际部署约束。

验收项目：

- 九项课程均通过实际点击/填写完成，错误动作和空表单不推进。
- 时间、人数、费用、角色与空间定义边界校验。
- 自动演示完成、暂停/继续、上一步/重启、键盘 Enter、Escape 和焦点返回。
- 角色目录、关闭/重开/文字切换、加载失败与重试。
- 完成课程期间无业务网络请求；嵌入子文档中没有脚本。
- 桌面与窄屏截图检查；真实系统页面和升级服务保持不变。
